# SJ Wheels

Tienda Shopify especializada en juegos de llantas para vehículos.

- **Tienda:** `5y82gi-yt.myshopify.com`
- **Tema base:** Horizon (Online Store 2.0, theme blocks)
- **Tema de trabajo:** `SJ Wheels — DEV (no publicar)` — `gid://shopify/OnlineStoreTheme/196061626701`
- **Tema en producción:** Horizon `gid://shopify/OnlineStoreTheme/196025975117` — **no se modifica**

## Reglas de trabajo

1. Todo el desarrollo va contra el tema DEV. El tema `MAIN` no se toca.
2. La publicación del tema es siempre una decisión manual del propietario.
3. No se inventan reseñas, stock, descuentos, certificaciones, garantías ni compatibilidades.
4. Nada se marca "Compatible" sin comprobación numérica de PCD, diámetro, ET y buje.
5. Los archivos propios llevan prefijo `sjw-` para no colisionar con actualizaciones de Horizon.
6. Precios, productos, dominios, pagos, envíos y políticas comerciales no se modifican sin
   autorización expresa.
